Building Your First Web Page — HTML and CSS Basics

Tutorials · 30 July 2026 · 6 min read

This very site is hand-built HTML and CSS. You can build a page today with two simple ideas: structure and style. Here is the mental model that makes it click.

Two Languages, Two Jobs

A web page is built from two things working together. HTML is the structure — the skeleton that says "this is a heading, this is a paragraph, this is an image." CSS is the style — the clothing that says "make headings large and green, give this box rounded corners." Keep those two jobs separate in your head and web development stops being intimidating.

HTML — Boxes With Names

HTML is just content wrapped in labelled tags. A heading is <h1>Title</h1>, a paragraph is <p>text</p>, an image is <img>. Tags nest inside each other like boxes in boxes, and that nesting is the whole structure of every page on the internet. Write a few tags in a plain text file, save it as .html, open it in a browser — and you have made a web page. That is genuinely all the first step is.

CSS — Rules That Target

CSS is a list of rules, each saying "find these elements, apply this style." h1 { color: green; } means "every h1, make it green." You select elements (by tag, class, or id) and declare properties (colour, size, spacing, layout). Modern layout uses flexbox and grid to arrange those boxes into columns and rows responsively. Learn to select and to space, and you can style anything.

How to Actually Start

Do not buy a course yet. Make one file, put a heading and a paragraph in it, open it, then add a <style> block and change a colour. That loop — write, save, refresh, see it change — is the entire feedback cycle of web development, and an afternoon of it teaches more than a week of watching videos.

A web page is structure (HTML) wearing style (CSS). Master that one distinction, build one real file, and the mystery of "how are websites made" quietly dissolves into something you can do.
